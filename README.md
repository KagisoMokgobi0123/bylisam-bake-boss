# BYLISAM Bake Boss

Design and develop a full-stack BYLISAM Muffin Sales Management Web Application for BYLISAM, a small homemade muffin business operating within a student residence. The application should function as a comprehensive business management system rather than an e-commerce or payment processing platform, focusing on efficiently managing inventory, customers, orders, rewards, and sales while collecting only the minimum personal information required. The system must support two user roles: Admin and Customer (Student). The Admin should have complete control through a comprehensive dashboard that enables management of muffin inventory, flavours, pricing, stock levels, customer accounts, loyalty points, rewards configuration, orders, walk-in sales, sales reports, WhatsApp notifications, and system settings. Inventory management must allow adding, editing, deleting, and updating muffin products, prices, flavours, and quantities. The loyalty programme should be fully configurable, allowing the Admin to define how many points customers earn per muffin or purchase, specify eligible products, set minimum redemption thresholds, choose reward types such as a free muffin, percentage discount, or fixed discount, and configure automatic reward expiry after a defined period such as one month. The Admin should be able to review all customer orders, approve orders, mark them as collected, automatically record completed sales, generate receipts, produce sales summaries and reports, and monitor customer reward balances. Include a dedicated Walk-in Order Panel for customers who do not register, allowing the Admin to capture only the customer's phone number, identify whether the customer is a student or non-student, select one or more muffin types with quantities, choose a payment method (Cash, EFT, etc.), automatically calculate the total, generate an order receipt, and once the order has been approved and marked as collected, automatically send the receipt together with a friendly WhatsApp message such as, "Thank you for supporting BYLISAM! 🧁 Your order has been collected successfully. We truly appreciate your support and hope you enjoy your freshly baked muffins. We look forward to serving you again soon!" The system must never process or store payment information but should record only the selected payment method for reporting purposes. Student customers should be able to register using their full name, email address, and password, with email ownership verified through an OTP before account activation. Login should require an email address and password and optionally support OTP verification for enhanced security. Registered customers should be able to browse available muffins, view prices, place orders, select a payment method without entering banking details, monitor order status (Pending, Approved, Ready for Collection, Collected), view loyalty points and available rewards, redeem rewards when eligible, view reward expiry dates, access previous orders, and manage their profile. The order workflow should follow this sequence: customer places an order, selects a payment method, order status becomes Pending, the Admin reviews and approves the order, the customer collects the order, the Admin marks it as Collected, and the system automatically records the sale, awards loyalty points where applicable, generates a receipt, and sends the receipt and thank-you message through WhatsApp. Privacy and security must be prioritized by storing only essential information including customer name, email address, securely hashed password, phone number (only when required for notifications), reward points, and order history, while never storing card numbers, banking details, payment credentials, or processing online payments. Organize the application into logical modules including Admin Dashboard, Inventory Management, Muffin Management, Price Management, Customer Management, Rewards Management, Orders Management, Walk-in Orders, Sales Reports, WhatsApp Notifications, System Settings, Customer Registration, Email OTP Verification, Login, Browse Muffins, Place Orders, Track Orders, Rewards, Order History, and Profile. The user interface should reflect the warm, inviting identity of BYLISAM with a modern, clean, responsive design that works seamlessly across desktop, tablet, and mobile devices, using Brown as the primary colour for navigation bars, buttons, headings, and primary actions, Cream for cards and content sections, and Ivory as the main background colour. The interface should feature rounded buttons and cards, consistent typography, bakery-inspired icons and subtle muffin-themed illustrations, intuitive navigation, smooth animations for buttons and page transitions, clear call-to-action buttons, visual confirmation after important actions, and colour-coded status badges for order progress. Rewards and loyalty information should be prominently displayed and easy to understand, while the ordering process should remain simple and require as few steps as possible. Overall, the BYLISAM Muffin Sales Management Web Application should communicate warmth, freshness, homemade quality, trust, simplicity, and student-friendly affordability while serving as the complete digital business management platform for BYLISAM, providing an efficient, secure, and user-friendly experience.
